# Learning Analytics

## Metric definitions

- Completion: activity wajib selesai / seluruh activity wajib.
- Engagement: active seconds teragregasi; bukan sekadar halaman terbuka.
- Mastery: evidence berbobot per kompetensi.
- On-track: expected progress berdasarkan jadwal dibanding actual progress.
- Improvement: perubahan score dari attempt pertama ke attempt terbaik/terakhir, keduanya ditampilkan jelas.

## Aturan

- Definisi metrik disimpan/versioned; jangan mengubah makna grafik diam-diam.
- Abaikan heartbeat tidak aktif dan clamp session abnormal.
- Tampilkan sample size dan last updated.
- Jangan membuat ranking publik.
- Sinyal risiko harus explainable dan dapat diperbaiki.

## Insight keren

- Mastery heatmap per kompetensi.
- Misconception map berdasarkan distractor terpilih.
- Assessment item analysis: difficulty, discrimination sederhana, omit rate.
- Learning-path bottleneck: lesson tempat banyak murid berhenti.
- Intervention impact: before/after dengan catatan bahwa korelasi bukan kausalitas.
- Teacher weekly digest berisi tiga prioritas tindakan, bukan hanya grafik.
