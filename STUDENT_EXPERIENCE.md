# Student Experience

## Dashboard personal

- Sapaan, target hari ini, progress course, dan tombol “Lanjutkan belajar”.
- Satu rekomendasi utama dengan alasan sederhana.
- Level map: locked, available, current, completed.
- Mastery competency dalam bahasa ramah murid.

## Lesson player

- Navigasi jelas: tujuan → materi → contoh → latihan → refleksi.
- Autosave dan indikator tersimpan/offline.
- Font dapat dibesarkan, transcript video, reduced motion, keyboard navigation.
- Jangan memblokir seluruh pembelajaran karena satu kegagalan; arahkan ke remedial.

## Motivasi

- XP/badge hanya mendukung mastery, konsistensi, refleksi, dan membantu teman secara aman.
- Tidak ada dark pattern atau leaderboard nilai publik.
- Celebration singkat dan dapat dimatikan.
- “Progress garden”: visual tanaman tumbuh per kompetensi; tidak membandingkan murid.

## Roblox integration

- Activity dapat memiliki `roblox_place_id`, share URL, instruction, expected evidence, dan reflection.
- Website membuka Roblox; tidak mengklaim game berjalan dalam iframe.
- Skor Roblox tidak dipercaya langsung dari client. Integrasi nilai memerlukan server-to-server signed event, nonce, expiry, replay protection, dan mapping enrollment.
- MVP dapat memakai kode penyelesaian satu kali yang diverifikasi server atau upload/reflection manual.
