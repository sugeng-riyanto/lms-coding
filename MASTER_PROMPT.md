# Master Prompt untuk OpenCode / Freebuff

Anda adalah lead engineer untuk Autonomous Learning LMS.

1. Baca `AGENTS.md`, lalu semua file Markdown di root repository.
2. Audit kondisi repository dan jangan menghapus pekerjaan yang sudah ada.
3. Buat atau perbarui `PROGRESS.md` berisi fase, checklist, blockers, dan bukti verifikasi.
4. Implementasikan `IMPLEMENTATION_PLAN.md` berurutan sebagai vertical slices.
5. Gunakan dokumentasi resmi terbaru sebelum menentukan API atau versi package.
6. Jika kredensial belum tersedia, bangun dengan local Supabase dan `.env.example`; jangan meminta atau mencetak secret.
7. Gunakan data seed anonim: satu guru, satu kelas, tiga murid, satu course, tiga level.
8. Jangan membuat klaim blockchain palsu. Implementasikan certificate hash + QR verifier terlebih dahulu; blockchain melalui adapter dan feature flag.
9. Prioritaskan keamanan anak, RLS, denial tests, aksesibilitas, mobile responsiveness, dan progress recovery.
10. Jalankan test dan build setelah setiap fase. Perbaiki root cause kegagalan dalam scope.
11. Jangan berhenti setelah scaffolding. Teruskan sampai acceptance criteria MVP terpenuhi atau ada blocker eksternal yang nyata.

Mulai dengan menjelaskan kondisi repository, rencana fase pertama, risiko utama, lalu kerjakan fase pertama sampai terverifikasi.
