# Teacher Dashboard

## Overview cards

- enrolled, active 7 days, on-track, needs attention;
- completion distribution;
- class mastery per competency;
- pending manual grading;
- recent submissions.

## Cohort matrix

Baris murid, kolom level/kompetensi. Warna tidak boleh menjadi satu-satunya pembeda. Setiap sel menunjukkan status, percent, mastery, last activity, dan drill-down.

## Student detail

- timeline belajar;
- lesson completion;
- attempt history;
- mastery evidence;
- feedback dan intervention notes;
- certificate history;
- audit-friendly score revisions.

## Alerts

- Berbasis aturan transparan.
- Tidak menggunakan ranking publik default.
- Guru dapat acknowledge, snooze, resolve, dan menulis intervention.
- Hindari notifikasi berlebihan; digest harian default.

## Export

- CSV nilai dan progress.
- PDF progress report opsional.
- Export mematuhi filter dan permission yang sama seperti UI.
